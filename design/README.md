# design/

Source files that are not part of the website build.

- `brand/` — logo and favicon exports from Figma (SVG + PDF), button states, and `mark-light.svg` / `mark-dark.svg`
  (sources of the header icons `src/assets/logos/mark-*.webp`, rendered at 136 and 204 px).
- `screens/` — `cover.png` (Figma working-file cover), `flying-ladders-home.png` (game home screen, source of the hero banner).
- `og-image.html` — source of `public/og-image.png`, the social preview.
- `prototypes/tangled-flows.html` — standalone prototype of the UX & Design hero animation.
