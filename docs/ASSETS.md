# Происхождение ресурсов

Графика, экраны приложений, before/after иллюстрации и социальные превью предоставлены владельцем в `vickand-site_100_90.html`, handoff и исходном GitHub-проекте. Внешние стоковые изображения или сгенерированные для этого обновления иллюстрации не добавлялись. Перед внешней публикацией владелец отвечает за права на предоставленные ресурсы и брендовые знаки магазинов.

`src/assets/img/shots/` содержит оптимизированные WebP с исходным разрешением. `shots/responsive/` — производные шириной360px для небольших экранов; оригинальные изображения сохранены. Дооптимизационные файлы также сохранены в игнорируемой `.reference/handoff/`. В сборке и браузере Python не нужен.

Шрифты Zilla Slab и Changa One хранятся локально. Тексты SIL Open Font License получены из официального репозитория google/fonts и поставляются в `public/licenses/zillaslab-OFL.txt` и `changaone-OFL.txt`. Не утверждается, что подписи с кириллицей обязательно используют каждый латинский шрифтовой файл: браузер применяет доступные подмножества/фолбэк исходного макета.

Для WebP инструмент provenance использует sidecar `.webp.json`; сборщик переносит его к соответствующему хешированному файлу без изменения пикселей.

Снимки QA показывают локальную сборку. Они не являются новым дизайном или ресурсами сайта и не должны включаться в `dist/`.
