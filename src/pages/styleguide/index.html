Components

Button, Input and Dropdown, built from the Figma UI-kit. Every variant is shown on light and dark. Themes follow the page, or force one with .is-light / .is-dark on any container. Hover, pressed and focus are real CSS states; the matrix forces them with .is-hover, .is-pressed, .is-focus.

Icons

Five icons so far, as an SVG sprite (src/partials/icons/sprite.html). They use currentColor, so they follow the text colour.
